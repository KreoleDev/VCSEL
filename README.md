# Pertech Production App

Electron production test app that uses the Pertech cloud API.

Cloud API URL:

```text
https://vcsel.pertechindustries.com/API/apps-api/
```

## Run on Windows

```powershell
npm install
npm run start:win
```

## Build Windows Installer

```powershell
npm run dist:win
```

The installer is written to the `dist` folder.
