1.  ************************************************

To run the VCSEL Analysis program (Auto)

     Menu options for the "VCSEL Light Dot Analysis"
     - "l" key press - allows the lot number to be entered.
     - "n" key press - allows for the manual entry of the serial number.
     - "a" key press - sets the "Acquired" state to "Auto". The program will automatically enter the serial number when pressing 's'
     - "m" key press - sets the "Acquired" state to "Manual". The user will manually have to enter the serial number
     - "s" key press - saves all the values within the camera window to a csv file in the "Home" file directory
     - "q" key press - closes the program just like pressing the box with the 'x' in the top right corner
     

1. Connect or confirm the usb camera to the computer.

2. Double click the desktop app named "VCSEL Light Dot Analysis".  Two windows should open one is a 'Terminal' window and the other will be showing a large "X" on the screen. If it fails to open, check that there is a camera connected to the usb.
   a. When running for the first time or every lot number change you will want to enter the 'Lot Number' for the VCSEL's you are calibrating.  To do this follow these steps
      1. Make sure the camera window has focus by clicking somewhere within the window.
      2. Press the "l" key, this will allow you to enter the lot number
      3. Enter the lot number from the package that the VCSEL's came in. Usually taped to the container the VCSEL's are in.
      4. After the lot number is entered press the "Enter" key. The lot number will now be recorded with ever 's' key entry.

3. Run the VCSEL calibration check for each VCSEL with Pertech Production software while leaving the camera window open in the background but visible.

4. After each VCSEL has been calibrated, you will want to click somewhere on the camera window that is in the background to give the window the focus.  Then press the "s" key on the keyboard. This will save the Brightness, Area, Lot Number, and Serial Number values into the "vcsel_log.csv" file located in the "Home" directory. Clicking the "s" key without giving the camera window focus first won't save the data to the file.

5. To close the camera window and exit the "VCSEL Light Dot Analysis", press the 'q' key or click the "x" box in the upper right corner of the terminal window. It is usually behind the camera window in the background.  Closing the camera window will not end the "VCSEL Light Dot Analysis" program it will only reopen a new camera window.


Note: VCSEL may need to be manually calibrated if the Brightness is below 150 and/or the Area is below 100 and when the 'Emitter' is unable to find a good value.

Manually Calibrating

After manually calibrating a VCSEL with the Pertech Production software, click somewhere on the camera window to give it focus then press the "m" key. This will set the "Acquired" status to "Manual". Now press the "n" key to manually enter the serial number shown on the Pertech Production software window and then press the "Enter" key. Now when pressing the 's' key to save the values it will record the manually entered serial number. If you leave the "Acquired" status in "Auto" and press the 's' key to save it might not be able to locate the serial number from the Pertech Production window and enter "UNKNOWN" in the place of the serial number which will be recorded in the csv file.


2. ****************************************************

To run the Area or Brightness Distribution report

1. Make sure that no other terminal windows are open.

2. Open a new terminal window. To locate the terminal window click on the circle in the lower left corner of the screen to access programs. Click on "Utility" and then click on "terminal" to open a new terminal window.

3. Type the following into the terminal window without the quotes.
	"source vcsel-venv/bin/activate"
	Then hit the enter key and type the next line without quotes followed by the enter key.
	"python plot_vcsel_area.py"
This will open a distribution report for the Area. To open a distribution report for the Brightness, type in the following line without the quotes and then hit the enter key.
	"python plot_vcsel_brightness.py"

4. To close the reports click on the "x" in the upper right corner of the window of the report. Close the terminal window in the same way when done.


3. *****************************************************

To reset the "vcsel_log.csv" file with new data

1. Open the "Home" folder. There should be a file called  "vcsel_log.csv"

2. Rename the file from "vcsel_log.csv" to "vcsel_log_old.csv" or in place of 'old' you can enter the date.

3. Close the "Home" folder and restart the "VCSEL Light Dot Analysis" program.  It will create a new "vcsel_log.csv" file. Remember, to save the area and brightness values to the "vcsel_log.csv" file. 



4. *********************************************************



Python script notes

Creates a file called "vcsel_log.csv" in the "Home" directory if not present already
 
Opens a camera connection to a usb port

Analyses the brightness and area of the VCSEL light by focusing on a calibrated paper screen. The brightness and area values are presented in the camera window in real time as the VCSEL is being calibrated with the Pertech Production software.

Allows for the manual entry of a Lot Number and serial number.

Saves the values from the camera window to the csv file

Extracts the serial number from the Pertech Production window (when open and visible). The Pertech Production software must be running in Auto calibration mode and not manual calibration mode.

Allow for the change in how the serial number is acquried. It can be set to acquire the serial number automatically by extracting it from the Pertech Production window or it can be manually entered. When the status is set to manual entry it will skip the extraction process of looking for a serial number in the Pertech Production window.

A termial window runs in the background with the camera window to show the status of the running python script.

     Troubleshooting ___________________________________________
     
     If your camera does not connect and you get an error (error window will shut down quickly) like the following,
     
     		"can't open camera by index"
     
     Then the index number within the program maybe wrong. To find cameras that are connected to Ubuntu type in the following command at the command prompt of the Ubuntu terminal,
     
     		ls /dev/video*
     
     This will show all connected cameras to the computer. See example below,
     
     		"/dev/video4  /ev/video5"
     
     Open the file "vcsel_analysis.py" in a text editor and look for the line below,
     
     		cap = cv2.VideoCapture(0)
     
     Change the "0" (in this example) to one of the numbers found in the search.  In this example we can try 4 or 5.  Save the file and try restarting the program.  If that index number does not work try the next one.
