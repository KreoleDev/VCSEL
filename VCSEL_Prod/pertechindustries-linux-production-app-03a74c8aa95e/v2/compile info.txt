This project uses Quasar.dev to build an Electron app for Debian Linux.

To build/run dev:
yarn quasar dev -m electron

To build release:
yarn quasar build -m electron

To package release into .deb:
(You will need electron-installer-debian installed global: sudo npm i --global electron-installer-debian)
Rename dist/electron/Pertech Production-linux-x64/Pertech Production to dist/electron/Pertech Production-linux-x64/pertech-production

Then from within dist/electron/
electron-installer-debian --src "Pertech Production-linux-x64/" --dest deb/ --arch amd64 --icon ../../pertech.png


Installing Plugins (from within src-electron directory):

sbffi:
sudo apt install cmake
sudo npm i --global prebuild
sudo npm i --global cmake-js
npm i sbffi

ref-napi: (used for 6100 api with sbffi)
npm i ref-napi

shared-structs: (used for 6100 api with sbffi)
npm i shared-structs

node-usb:
npm i usb

serialport:
npm i serialport

In order to get electron preload to work had to modify electron-main.js to have:

webPreferences: {
      contextIsolation: true,
      nodeIntegration: true,
      sandbox: false,
      // More info: https://v2.quasar.dev/quasar-cli-webpack/developing-electron-apps/electron-preload-script
      preload: path.resolve(__dirname, process.env.QUASAR_ELECTRON_PRELOAD)
    }
