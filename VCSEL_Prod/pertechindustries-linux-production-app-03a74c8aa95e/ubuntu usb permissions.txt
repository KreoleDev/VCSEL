Ubuntu 14.04 Setup:



Navigate to /etc/udev/rules.d



Create pertech-usb.rules and type:



SUBSYSTEM=="usb", ATTR{idVendor}=="1431", ATTR{idProduct}=="6100", MODE:="0666"

(Can leave off idProduct to support all pertech usb devices)



Save file and restart computer


To allow serial for user perform:

sudo usermod -aG dialout youruser


Current VCSEL Programmer On Ubuntu:



The 7680 VCSEL flow uses the Devantech USB-ISS serial bridge, not the old 6100 USB device.

Observed device:

Bus 003 Device 002: ID 04d8:ffee Microchip Technology, Inc. Devantech USB-ISS

Observed serial node:

/dev/ttyACM1



Recommended rule for the VCSEL programmer:

SUBSYSTEM=="tty", ATTRS{idVendor}=="04d8", ATTRS{idProduct}=="ffee", MODE:="0666", GROUP="dialout", ENV{ID_MM_DEVICE_IGNORE}="1"



Then reload rules and replug the device:

sudo udevadm control --reload-rules
sudo udevadm trigger



Important:

The application opens the VCSEL programmer through the serial device (/dev/ttyACM*), so the user must be in the dialout group.

After running:

sudo usermod -aG dialout youruser

log out and log back in, or reboot, before testing again.
